\section*{Goal and current status}

Project 1 asks whether a daily agent can collect machine-learning research and
organize it as an evidence-backed knowledge graph. The implemented
\texttt{paper-fetcher-agent} ingests arXiv and enabled public RSS or Atom feeds,
extracts grounded features, atomically rebuilds the graph, computes analyses,
and persists SQLite plus bounded JSON outputs. GitHub Actions schedules it each
day at 13:17 UTC and supports manual runs
\reposource{https://github.com/garyzhang1006/paper-fetcher/blob/main/.github/workflows/daily-arxiv-fetch.yml}{workflow}.

\section*{How the graph works}

Document nodes connect to topics, methods, research goals, datasets, metrics,
and arXiv categories. Semantic edges require exact extractor evidence or source
metadata; free keywords do not create them. \texttt{RELATED\_TO} uses bounded
IDF-weighted supported-concept overlap, threshold 0.20, and at most ten
neighbors per document. Hubs use weighted PageRank and degree; clusters use
related edges scoring at least 0.35. Search and five bounded JSON APIs expose
placement explanations, hubs, clusters, and topic trends
\reposource{https://github.com/garyzhang1006/paper-fetcher/blob/main/docs/PROJECT_1_SYSTEM_REPORT.md}{system report}.

Summaries copy the first abstract or feed-summary sentence and retain
provenance, avoiding generated factual claims. Seven-day recent and baseline
windows ending August 6 have status \texttt{ok}; no topic met both the
three-document minimum and positive-growth condition for an emerging-topic label
\reposource{https://github.com/garyzhang1006/paper-fetcher/blob/main/docs/PROJECT_1_SYSTEM_REPORT.md}{system report}.

\section*{Scope and remaining limits}

Public feeds do not cover every blog or social platform; Reddit input comes
from one public subreddit. The rules extractor has a finite vocabulary, so a
missing edge can mean missing evidence or an unrecognized concept. No
human-rated summary study has been run. Trends describe this corpus, not
research quality or future impact.

The first August 6 arXiv smoke run found 3,021 submissions beyond the configured
200-paper safety cap. The checkpoint was deliberately rebased to August 6 to
keep the corpus bounded, so papers not already stored from July 13 through that
rebase time were skipped
\reposource{https://github.com/garyzhang1006/paper-fetcher/blob/main/docs/PROJECT_1_SYSTEM_REPORT.md}{system report}. Category-classifier predictions
are not graph ground truth and do not create graph edges; classification
results remain documented in the separate four-page classification report.
